# Asset Register

## Supplied source

- `logo_full.jpg` — original NDCAK identity artwork supplied with the PRD package.

## Generated product asset

- `../../public/og.png` — original wide social preview for website sharing and metadata. The artwork uses the approved navy, ivory, green, and gold direction and contains no event details that still await committee confirmation.
- `brand/ndcak-mark.png` — compact loop-and-crests mark for headers, icons, and constrained UI placements. The public copy is at `../../public/brand/ndcak-mark.png`.
- `brand/ndcak-lockup.png` — refined full identity with corrected spacing and canvas proportions for larger brand placements. The public copy is at `../../public/brand/ndcak-lockup.png`.

Both logo variants were created with the built-in image generator from `logo_full.jpg`, then losslessly cropped to their production aspect ratios. The source image remains unchanged.

Architecture visuals are maintained as editable Mermaid diagrams in `../architecture` so labels, relationships, and state transitions remain exact and versionable.
