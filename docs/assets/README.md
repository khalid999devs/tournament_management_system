# Assets

- `logo_full.jpg` — the original NDCAK identity artwork the association
  supplied. Everything else was derived from it.
- `brand/ndcak-mark.png`, `brand/ndcak-lockup.png` — the full-quality masters.
  The app ships the compressed `.webp` versions in `public/brand/`, which are
  over 95% smaller; regenerate those from these if the artwork changes.
- `screenshots/` — the images used in the root README, captured from the demo
  data the test suite seeds, never from real participants.
